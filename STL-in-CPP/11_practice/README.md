# STL Practice

Solve these without looking at solutions:

1. Find frequency of every number using `unordered_map`.
2. Remove duplicates from a vector while preserving order.
3. Find the second largest element with `set`.
4. Sort pairs by second value descending.
5. Find top K largest elements with `priority_queue`.
6. Merge two sorted vectors.
7. Find first and last occurrence with `lower_bound` and `upper_bound`.
8. Check whether two vectors are disjoint.
9. Group strings by first character using `map`.
10. Implement a leaderboard using `map` + `priority_queue`.
11. Solve sliding-window maximum with `deque`.
12. Build a word-frequency counter using `unordered_map`.
13. Find common elements using set intersection.
14. Use `ranges::filter` and `ranges::transform` in C++20.
15. Create a custom comparator for sorting students.
